News from Sanctuary Alpha v0.7

RELEASE CHRONICLE · 03 OCTOBER 2026

A second chance, forged in gold.

The Token of Regret resets allocated stat and skill points. Find it in every act, on every difficulty, for 250,000 gold before native shop discounts.

  • 32 unique trinkets: Nightmare and Hell ordinary cows each have a 1 in 2,000 trinket route.
  • Smelting rebalanced: lower-level set items return more modest runes.
  • Worldforge Shards: the crafting relic receives a distinct name; its item code and recipes remain compatible.
  • Companions assembled: Blood Raven, Cow King, Summoner and two Doom Knight roles, with configurable equipment and portraits.
  • Sovereign Wardens: 30% more health across difficulties and a reduced rune-bonus chance.

The launcher adds offline map rerolling, the hero editor gets a clearer file picker, and the wiki and Android companion follow the new release.

Begin your journey

  1. Install the complete mod

    Close D2R. Extract the complete mod into D2RMM’s mods folder. Keep the stable folder name D2PLUS_Alpha_v05_Complete. Disable older overlapping D2PLUS modules, select your options and click Install Mods.

  2. Set up the launcher

    Install or extract the optional Windows launcher. Select your D2R executable and installed mod folder, or import your working shortcut.

  3. Enter offline Sanctuary

    Launch your offline character. Use “Reset offline maps” when you want maps to reroll on each new game; relaunch D2R after changing it.

Requires your own copy of Diablo II: Resurrected. Back up your offline characters before testing an alpha release.

Questions at the gate

Does the launcher install the gameplay mod?

The complete mod is a separate download. Install it through D2RMM using the included instructions. The launcher contains the companion tools and can download the mod archive.

What does resetting maps do?

The launcher passes D2R’s offline-map reset argument. While enabled, new games reroll maps. It does not delete character files. Changing the option requires relaunching the game.

What has been tested?

Automated data, launcher and package checks accompany this release. Live D2R gameplay, Windows display scaling and Android device behavior still need player testing.

Where can I report an issue?

Use the GitHub repository’s bug-report form. Include your version, selected options and steps to reproduce. Remove personal information from logs.
