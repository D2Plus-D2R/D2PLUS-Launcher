ALPHA V1.3 · 26 OCT 2026

Charm weight: how the 50-point limit works

Your charms can total 50 weight points before penalties begin. That is combined weight, not 50 charms: magic Small / Large / Grand Charms weigh 1 / 2 / 3, most unique charms weigh 5, and crafted Oaths weigh 7. Check Advanced Character Stats for your total. Seven new craftable Oaths share an aura with you and nearby allies, including your mercenary.

Begin your journey

  1. Install the Windows launcher

    Download and run the Alpha V2.0 installer. Your offline wiki, hero editor and complete gameplay package are included.

  2. Choose your game and install

    In Setup, browse to D2R.exe, then click Install Alpha V2.0. Close D2R first. The launcher configures the mod folder and launch arguments, and retains the previous mod output as a backup. If Windows denies access to the game folder, reopen the launcher using Run as administrator.

  3. Enter offline Sanctuary

    Click Launch D2PLUS and select an offline character. Existing players should retain their previous output folder name so their characters stay available.

Prefer D2RMM?

Extract the Complete D2RMM ZIP into the D2RMM application’s mods folder. Enable D2PLUS - Alpha V2.0 Complete, disable older complete D2PLUS bundles and included test add-ons, then click Install Mods. This release is a fixed-settings snapshot.

Requires your own copy of Diablo II: Resurrected. Back up your offline characters before testing an alpha release.

Questions at the gate

How do I enable melee splash damage?

Want melee splash damage? Buy the optional melee splash charm from Gheed in Act I and keep it in your character’s inventory to enable the effect. Move it to your stash to turn it off.

Does the launcher install the gameplay mod?

Yes. The Alpha V2.0 launcher bundles the complete gameplay snapshot. Select your D2R.exe, then click Install Alpha V2.0. The standalone D2RMM ZIP contains everything in one mod. Disable the older D2PLUS bundle and included add-ons before installing it; no previous version is required.

What does resetting maps do?

The launcher passes D2R’s offline-map reset argument. While enabled, new games reroll maps. It does not delete character files. Changing the option requires relaunching the game.

What has been tested?

Automated data, launcher and package checks accompany this release. Live D2R gameplay, Windows display scaling and Android device behavior still need player testing.

Where can I report an issue?

Use the GitHub repository’s bug-report form. Include your version, selected options and steps to reproduce. Remove personal information from logs.
