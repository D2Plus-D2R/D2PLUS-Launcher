News from Sanctuary AlphaV0.8.2

RELEASE CHRONICLE · 09 OCTOBER 2026

The Warden takes form.

  • A new monster guards the act bosses, featuring a custom model.
  • 37 uniques rebalanced, plus updated equipment visuals.
  • Storm Lance improvements and skill tooltip fixes.
  • Updated wiki, hero editor, all 33 build guides, and Android companion.
Read full patch notes

AlphaV0.8.2 brings the current D2PLUS gameplay and companion tools together.

  • A new monster guards the act bosses, featuring a custom model.
  • Warden claws gain a fire effect and added fire damage equal to 20% of physical damage; all six Warden definitions have 20% more life in Normal, Nightmare and Hell. Andariel and the other act-boss models keep their own appearances.
  • 37 unique items rebalanced: 19 nerfs to strong early/mid-game outliers and 18 buffs to overlooked items. New drops use the current values; existing saved items retain their prior rolls.
  • Storm Lance releases aimed lightning bolts from range, gains primary bolts at total skill levels 10 and 20, and carries 50% native weapon damage on the primary bolts. Impact chains use 25% skill lightning with the existing three-jump limit.
  • 68 equipment appearances receive custom inventory art and/or visual treatment, including class capstone sets and Diablo I-inspired uniques. Long capstone set-name localization keys are repaired.
  • Updated skill-panel border/background and corrected numeric tooltips for Storm Lance, Arcane Tempest, Soul Harvest and Ancestral Standard.
  • Wiki and hero editor now share the current unique, set and skill names. All 33 build guides are revised for the current skills, with explicit prerequisites and legal point budgets.
  • Complete fixed-settings D2RMM package, bundled Windows installer and portable launcher, offline wiki and Android companion are synchronized to AlphaV0.8.2. Rune/material stash tabs, crafting, mercenaries and all 163 enabled runewords remain included.

Begin your journey

  1. Install the Windows launcher

    Download and run the AlphaV0.8.2 installer. Your offline wiki, hero editor and complete gameplay package are included.

  2. Choose your game and install

    In Setup, browse to D2R.exe, then click Install AlphaV0.8.2. Close D2R first. The launcher configures the mod folder and launch arguments, and retains the previous mod output as a backup. If Windows denies access to the game folder, reopen the launcher using Run as administrator.

  3. Enter offline Sanctuary

    Click Launch D2PLUS and select an offline character. Existing players should retain their previous output folder name so their characters stay available.

Prefer D2RMM?

Extract the Complete D2RMM ZIP into the D2RMM application’s mods folder. Enable D2PLUS - AlphaV0.8.2 Complete, disable older complete D2PLUS bundles and overlapping add-ons, then click Install Mods. This release is a fixed-settings snapshot.

Requires your own copy of Diablo II: Resurrected. Back up your offline characters before testing an alpha release.

Questions at the gate

Does the launcher install the gameplay mod?

Yes. The AlphaV0.8.2 launcher bundles the complete gameplay snapshot. Select your D2R.exe, then click Install AlphaV0.8.2. A separate all-in-one D2RMM mod remains available.

What does resetting maps do?

The launcher passes D2R’s offline-map reset argument. While enabled, new games reroll maps. It does not delete character files. Changing the option requires relaunching the game.

What has been tested?

Automated data, launcher and package checks accompany this release. Live D2R gameplay, Windows display scaling and Android device behavior still need player testing.

Where can I report an issue?

Use the GitHub repository’s bug-report form. Include your version, selected options and steps to reproduce. Remove personal information from logs.
