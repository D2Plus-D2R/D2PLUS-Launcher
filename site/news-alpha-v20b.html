NOVEMBER 21, 2026 · ALPHA V2.0b

Smaller loads. Easier updates.

A fresh complete D2RMM mod and a new launcher, focused on fixing installation problems and making the next update much smaller.

Less memory needed when the Warden appears

The Warden uses less memory when it loads. This should help on PCs that struggled near Andariel or Duriel. Very close-up details may look a little softer.

We still need reports from players who had those crashes to know how much this helps.

Fixed full-mod installation

The launcher could reject the complete mod because of an old size limit. That limit is fixed. Installation also checks your files and free space, and keeps the previous mod as a backup.

Checking large downloads now uses less memory.

Smaller updates through the new launcher

Install the V2.0b launcher once. On its Install & Updates page, you can scan for missing or damaged files and get the files needed for an update or repair.

Automatic updates are on by default and can be switched off. Close D2R and restart the launcher to apply a downloaded update. Your settings and characters stay in place, and backup copies are kept. Occasionally, a major launcher change may still need a new installer.

Better checks before launch

The launcher checks key encounter files before starting the game and explains how to repair them if something is missing or changed.

Act III sorcerer animation fix

The Act III sorcerer now has the missing animations and plays them at the right speed.

A fresh complete D2RMM package

  1. Close D2R and extract the Complete D2RMM ZIP into D2RMM/mods.
  2. Keep the D2PLUS_Alpha_v20b_Complete folder name. Disable older complete D2PLUS bundles and overlapping test addons.
  3. Enable D2PLUS - Alpha V2.0b Complete and click Install Mods.
  4. Keep your existing output folder name and save path so your characters remain available.

No previous D2PLUS mod is required. Gameplay balance and character saves are unchanged. The existing V2.0a Android companion and reference data remain compatible.

If you still crash

The packages, installer and update system have passed our checks. Testing on affected PCs is still needed. If a crash continues, please report your D2R version, difficulty, graphics settings and whether it happens while loading or after entering. Attach the crash log after removing personal details.
