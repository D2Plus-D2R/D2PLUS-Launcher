Install with D2RMM

  1. Close D2R and back up your offline characters and shared stash.
  2. Extract the Complete D2RMM ZIP into the D2RMM application’s mods folder.
  3. Enable the new complete D2PLUS package. Disable older complete D2PLUS packages and overlapping D2PLUS add-ons.
  4. Click Install Mods in D2RMM, then launch the installed mod and choose an offline character.

When updating, keep the same installed output mod name and save path. Switching either can make your existing characters appear missing because the game is looking in a different folder.

Install with the Windows launcher

  1. Close D2R, run the Windows installer and open D2PLUS Launcher.
  2. Choose your D2R.exe in Setup and confirm the intended mod and save paths.
  3. Use Install Alpha V2.0a to apply the bundled gameplay files. Installing the launcher application alone does not replace your installed gameplay.
  4. Click Launch D2PLUS and choose an offline character.

A portable Windows launcher ZIP is also available. Extract the whole archive and keep its files together.

Wiki, Hero Editor and Android reference

The launcher includes the current offline wiki and Hero Editor. You can also browse the online wiki, download the standalone offline wiki, or download the signed Android companion APK.

The Android companion contains an offline reference; it does not run Diablo II. Existing signed v0.8 and later installations update in place. Older v0.7 installations use a different signing key; read the release notes before upgrading.

Common installation questions

Which ZIP belongs in D2RMM?

Use the file named D2PLUS_AlphaV2.0a_Complete_D2RMM.zip. The installed-snapshot archive is for the launcher, and the portable launcher archive is a Windows application.

Where are my characters after an update?

Check that the installed output mod name and save path match your previous setup. The launcher’s Character saves controls show the selected folder and offer backups. Do not delete or rename saves to troubleshoot a path mismatch.

Can I combine older D2PLUS add-ons?

The complete V2.0 package replaces the older complete package and overlapping D2PLUS add-ons. Compatibility with unrelated mods is not guaranteed; overlapping tables and assets can conflict.

What should I back up?

Close the game and Hero Editor before copying the selected save folder, including character files and the shared stash. The Getting Started guide explains the launcher’s save-path, backup and restore controls.
