# D2PLUS — Alpha v0.5

This release pairs the author-tested working gameplay snapshot with the updated launcher and offline wiki.

## Gameplay

- Act I Blood Raven, Act II Cow King, Act III D1-style robed Summoner, and Act V Doom Knight mercenaries.
- Dreadguard: Grave Strike, Dread Cry and Bone Guard. Red Doom Reaver: Ruin Frenzy, Siphoning Blade and Reaver's Challenge. Both display a fixed sword.
- Six Hell-only luxury potions with 10-minute buffs and level-60 requirements, sold by Akara, Lysander, Alkor, Jamella and Malah.
- Sovereign Wardens configured for each act boss; Countess drop tables match Normal, Nightmare and Hell.
- New transparent 1×1 Worldstone Shard inventory art; Cube recipes unchanged.
- Custom rune-name and numeric passive-tooltip fixes retained.

The Summoner robe also affects the Summoner boss. Failed isolated Sorcerer/hat/staff experiments are excluded. Astral Reliquary and Sovereign Dunes remain outside the working snapshot because portal-entry crashes are unresolved. Furnace content is retained.

## Launcher and offline wiki

- Alpha v0.5 labels, news, patch notes and installation instructions.
- Verified gameplay snapshot download in Install & Updates.
- All 135 hireling records refreshed; six new Doom Knight skills, six potion entries and Warden drop information added.
- Existing settings, optional damage companion, hero editor and historical guides retained.

## Downloads and installation

Use **D2PLUS_Alpha_v0.5_Working_Shard.zip** for the complete installed gameplay snapshot. Close D2R, back up your output and saves, and merge `data` plus `modinfo.json` into `mods/D2RMM/D2RMM.mpq`. Preserve your working output name and save path. This is not a D2RMM source package. Reinstalling older source mods overwrites it.

**D2PLUS_Worldstone_Shard_Only.zip** is only an artwork addon for an already working v0.5 setup. Extract into D2RMM's source `mods` directory and load after D2PLUS/item graphics mods.

The Windows installer/portable package updates the launcher and bundled offline wiki. Installing the launcher does not install gameplay data. The standalone wiki ZIP opens at `docs/wiki/index.html`. The GitHub source ZIP contains launcher source, not rebuilt gameplay source.

Automated launcher/setup/wiki checks and archive integrity checks run in the release workflow. Live Windows installation, game launching and the final Shard sprite appearance still require validation. The installer is unsigned. Keep backups and use offline single-player.
