# D2PLUS Alpha v0.8

Complete release based on the supplied installed D2RMM snapshot: rune stash UI,
material stash tab, updated skills, simpler skill icons and Alpha v0.8 splash art.

- Windows launcher bundles gameplay and offers Install Alpha v0.8 after selecting D2R.exe.
- Guided installation verifies the package and every installed file, retains previous mod output,
  preserves its savepath, and configures launch arguments. D2R must be closed.
- Separate all-in-one D2RMM mod recreates the complete fixed-settings snapshot.
- Offline wiki and hero editor use current skill/item names and all 163 enabled runewords.
  Native IDs follow the installed full tables, including Ritual before custom runewords.
- Existing v0.7 features, including respec tokens, smelting, mercenaries and map rerolling, remain.

Install the Windows setup EXE for the easiest route. Use the Complete_D2RMM ZIP only
with the D2RMM application. The Installed_Snapshot ZIP is also available for manual installation.
Requires a separately installed copy of Diablo II: Resurrected. Fixed snapshot settings are included;
individual feature toggles are not part of this all-in-one mod.

Automated checks cover package integrity, recreated D2RMM output, catalogs and installer behavior.
Live D2R gameplay and Android device behavior are not certified by those checks.

The editor preserves the new proof and roll save stats. Its existing safety checks
still reject 33 unsupported item templates; 719 tested templates remain supported.
The Android reference content is updated, but the installable APK is pending the
original signing key. It is not advertised as an available signed download.
