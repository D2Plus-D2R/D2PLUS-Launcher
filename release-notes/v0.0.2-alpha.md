# D2PLUS Launcher — Alpha 0.0.2

First named desktop alpha: a D2PLUS-themed Windows launcher that brings your installed mod, offline wiki, hero editor and optional damage companion together.

## Included

- Windows x64 installer with desktop and Start-menu shortcuts, plus portable ZIP.
- Reference-artwork launcher layout, native minimize/close controls and single-instance handling.
- First-run path wizard, working-shortcut import, persistent options and D2RMM download support.
- Bundled wiki 1.0.6 and existing hero editor; damage numbers off by default for new settings.
- Preserved mod folder selection, additional arguments, companion compatibility checks and cleanup.

## This version

The launcher previously used internal version `0.2.0`. It is now named **Alpha 0.0.2** (`0.0.2-alpha`, tag `v0.0.2-alpha`). Mod and wiki versions remain independent. This release renames the launcher and adds the GitHub project page; no gameplay or item balance changes are included.

## Install

Close the old suite console. Use the installer, then open the desktop shortcut and check paths/arguments. For portable use, extract the entire ZIP and keep its files together. Use your existing D2PLUS mod installation; apply changed options using **Install Mods** in D2RMM.

## Test status

Automated policy, API, persistence, setup and desktop-shell tests: 22 passed. ZIP and installer archive integrity checked. Live Windows installation, DPI/layout, game launching and companion compatibility still need testing. The installer is unsigned.

The damage overlay measures monster health loss, including combined hits, mercenaries and summons. It is not an exact player-only DPS meter or critical-strike detector. Use offline single-player and windowed/borderless mode.
