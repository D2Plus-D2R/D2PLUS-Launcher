# D2PLUS Alpha V1.2

Lilith, Daughter of Hatred has arrived! You can find her alongside Mephisto on Normal, Nightmare and Hell.

- Added Lilith with her own model, animations and demonic voice lines.
- Cleaned up Azmodan's attack, walking and death animations.
- Fixed targeting for Mephisto and the Memory of Mephisto.
- Updated the splash screen to Alpha V1.2. Mephisto trophies remain exclusive to Mephisto.

**D2RMM update:** Close the game and back up your saves. Extract `D2PLUS_AlphaV1.2_Complete_D2RMM.zip` into D2RMM's `mods` folder. Disable the old D2PLUS package and included test addons, enable **D2PLUS - Alpha V1.2 Complete**, and click **Install Mods**. Keep your existing output mod name and save path. No new character or previous version is required.

**Launcher update:** Install the Alpha V1.2 launcher or extract the full portable ZIP. Keep your current game and mod paths, then install the bundled Alpha V1.2 gameplay files from Setup.

The Complete_D2RMM ZIP is the standalone mod for D2RMM. The Installed_Snapshot ZIP is the launcher payload, not a D2RMM input mod. Existing saves are not included or replaced. The offline wiki and Android companion remain at their previously published versions.
