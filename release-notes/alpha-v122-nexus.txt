D2PLUS Alpha V1.2.2: A little easier to get started

This is a small quality-of-life update to help you spend less time looking
for files and more time playing.

The launcher now shows exactly where your characters are saved. Open Saves
takes you straight there, while Back Up Saves creates a checked, timestamped
copy of your characters and shared stash. Close the game first, then use
Open Backups whenever you need to find your latest copy.

We've also added a short Getting Started guide at
https://d2-plus.net/getting-started.html, on GitHub and inside the launcher.
It covers installation, updating, backups, Gheed's optional melee-splash
charm, material storage and the basics of Accursed rituals.

Controller players also get improved potion alignment, stash navigation and
dark gothic stone panels, with a cleaner border-free inventory surround.

The splash screen now reads Alpha V1.2.2. This update does not change
gameplay balance or require a fresh character.

Updating is simple: close D2R and back up your saves. Install the new
launcher, or replace the older complete D2PLUS package in D2RMM with the
new version and click Install Mods. Keep your existing output mod name
and save path so the game continues using your current characters.

Thanks for playing, sharing feedback and helping D2PLUS grow.
