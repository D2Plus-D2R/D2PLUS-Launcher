# Alpha V0.9 — Harrogath stash hotfix (0.9.1-alpha)

This release fixes the Act V stash opening but rejecting item transfers. It restores the native Bank identity for Harrogath preset 154 in both objpreset tables. The custom chest model and moved position remain; the stash uses the standard chest facing.

These two table cells are the only game-data changes from the published Alpha V0.9 release. Azmodan and all Alpha V1.0 test work are excluded. Sovereign Warden remains unchanged.

## Downloads and upgrading

- Windows installer and portable launcher **0.9.1-alpha** bundle the corrected snapshot. After updating the launcher, close D2R and click **Install AlphaV0.9 Stash Hotfix** to install the game files.
- **D2PLUS_AlphaV0.9.1_Complete_D2RMM.zip** is the complete standalone mod. Replace the existing `D2PLUS_Alpha_v09_Complete` source folder, enable it, disable older overlapping D2PLUS modules, and click Install Mods. No separate bank addon is required.
- **D2PLUS_AlphaV0.9.1_Installed_Snapshot.zip** is the corrected installed output for manual installation.
- Preserve your existing mod output name and save path so your characters remain available. Start a new game after installing. Character saves are not modified.
- Android companion, wiki/reference data and their V0.9 filenames are unchanged because this fix only affects the game's Act V bank.

## Verification

Both packages are rebuilt from SHA-256-pinned public V0.9 archives. All game files except the two objpreset tables must remain byte-identical; each table changes only the Act V preset 154 ObjectClass from D2PlusHarrogathBank to Bank. The standalone D2RMM output is checked against the snapshot and its full installation manifest. Release downloads are checksum-verified.

In-game item-transfer retesting is pending. Check a low-value item in personal and shared stash tabs after upgrading. The previous V0.9 release remains available for rollback.
