D2PLUS Alpha v0.7

Final gameplay addition: Token of Regret. This consumable resets all allocated skill and stat points using the native respec function. One inventory square, new transparent artwork. Sold by Akara, Drognan, Ormus, Jamella and Malah on Normal, Nightmare and Hell. Listed base price is 250,000 gold; native quest and equipment discounts still apply. Malah uses an internal cost-adjusted variant for her native price multiplier. Neither variant is added to monster drops.

Trinkets: eligible Nightmare and Hell cows now select the unique trinket route at 1 in 2,000 per kill on either difficulty. The 32 trinkets have equal weight (1 in 64,000 for a particular trinket). Successful selection replaces ordinary loot for that resolution. Cow King-specific tables and Normal are unchanged.

Set smelting: use the higher of set quality level and required level. Maximum rewards: levels 1-15 Ith; 16-30 Ort; 31-45 Sol; 46-60 Hel. Only excessive existing payouts are reduced. Ingredients, higher-level sets and unique smelting remain unchanged.

Worldforge Shard: renamed the custom crafting Worldstone Shard without changing its wss item code, save identity, artwork, 1x1 size or eight cube recipes. Native regional Worldstone Shards retain their names.

Carries forward the complete working D2PLUS baseline, mercenary models/equipment/portraits, six ten-minute Hell buff potions, Sovereign Wardens with 30% more health and reduced rune-bonus frequency, and custom loading artwork updated to Alpha v0.7. The separate Act V portrait option defaults off. Existing dungeon prototypes retain their previous state.

Companion update: launcher map-reset checkbox, hero-editor file-picker repair and new item data, refreshed offline wiki, Android companion update using its original application identity and signing key. Website restyled as a classic dark stone and gold Diablo II-inspired portal.

Validation: automated installation, data, launcher and content checks. Live D2R gameplay, Windows installation and Android device testing are still required. Back up offline characters before alpha testing.
