D2PLUS Alpha V1.2.2

The launcher now shows your exact character-save folder, with Open Saves,
Back Up Saves and Open Backups controls. Backups include the shared stash,
are timestamped and checked against the originals, and require D2R to be closed.

A short Getting Started guide is available on the website, on GitHub and
inside the launcher. It covers installation, updates, save backups, Gheed's
melee-splash charm, magic find, material storage and Accursed rituals.

The game and launcher splash now read Alpha V1.2.2.
Gameplay content and balance are unchanged from the published Alpha V1.2.
Controller HUD potion alignment and stash navigation are improved, with dark
gothic stone backgrounds. The added outer inventory border has been removed.

Update: Close D2R and back up your saves. Install the new launcher, or replace
the old complete D2RMM package with the new complete package and Install Mods.
Keep your existing output mod name and save path. No new character is needed.
