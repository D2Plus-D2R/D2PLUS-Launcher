# SlashDiablo Touch experimental Android build

Independent experimental build branch, D2PLUS main is unchanged. Uses public D2Android 1.5.0 source. SlashDiablo normally uses 1.13c; the upstream D2Android game hooks require 1.13d, so multiplayer remains unverified. No Blizzard or SlashDiablo proprietary game files are bundled. See Actions for APK build results. The patch keeps the D2Android touch/gamepad input and unblocks only normal user action commands online, not offline gameplay modifications.
