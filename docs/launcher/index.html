Install & Updates

Install D2PLUS Alpha v0.8

Select your D2R.exe in Setup, then install the complete bundled gameplay files. No separate mod-manager steps or downloads are needed. Existing mod output is retained as a backup.

D2RMM (optional)

Keep your working version, or download the stable Windows ZIP. Its published SHA-256 is checked before the file is made available.

Extract the downloaded ZIP yourself, then select D2RMM.exe in Setup.

D2PLUS

Download the complete Alpha v0.8 D2RMM mod. Extract into D2RMM/mods, keeping the D2PLUS_Alpha_v08_Complete folder. Disable older D2PLUS modules, enable D2PLUS - Alpha v0.8 and click Install Mods. Keep your working output name, launch arguments and save path.

04 / Optional overlay

See every battle unfold.

Damage numbers are off by default. Enable them from Home after setup when you want to test the overlay.

Use windowed or borderless mode. On first use, hover over roughly 3–7 monsters at different positions to calibrate. Keep the DPS meter clear of your Practical HUD.

Measures monster health loss, including combined hits, mercenaries and summons. It is not precise player-only DPS or a confirmed critical-strike detector. Original memory checks remain enabled; compatibility must be checked on your installation.
